# NOVA

NOVA is a fictional streetwear store I made as my end term project for SST Web Dev 101. It's a single page shop with a product grid, a featured sneaker, a specifications table, reviews and an order form.

Live site: https://YOUR-USERNAME.github.io/nova/

## Built with

- HTML
- CSS (Flexbox, Grid, media queries, keyframe animations)
- Some JavaScript for the cart counter

I didn't use any frameworks or libraries. I wanted to see how much I could do with plain HTML and CSS, so things like size selection, the quantity limit and the order confirmation work without JavaScript.

## Features

- Responsive layout for desktop, tablet and mobile
- Product grid with six items and an add-to-cart button on each
- Featured product with size and quantity options
- Specifications table
- Order form with validation and a confirmation message
- Cart count in the navbar

## How to run

Download or clone the repository and open `index.html` in a browser.

## What I learned

The hardest part was getting the layout to work on mobile without anything overflowing. I also ran into a specificity problem where my confirmation message kept showing up grey, which helped me actually understand how specificity works.
